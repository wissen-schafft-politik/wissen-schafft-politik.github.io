2. Hosting (GitHub Pages)

Diese Website wird als statische Seite über GitHub Pages (GitHub, Inc., USA) bereitgestellt. Beim Aufruf verarbeitet GitHub technisch notwendige Daten (u. a. IP-Adresse) in Server-Logs. Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO (berechtigtes Interesse an der sicheren Bereitstellung). Details: GitHub Privacy Statement.

3. Keine Cookies, kein Tracking

Diese Website setzt keine Cookies, verwendet keine Analyse- oder Tracking-Dienste und bindet keine Inhalte von Drittservern ein. Schriften werden lokal gehostet (keine Verbindung zu Google-Servern).

4. Profildaten im Verzeichnis

Die im Verzeichnis angezeigten personenbezogenen Daten (Name, Position, Institution, Kontaktdaten, Selbstbeschreibung, Links) wurden von den gelisteten Personen selbst eingetragen und beruhen auf deren ausdrücklicher Einwilligung (Art. 6 Abs. 1 lit. a DSGVO). Die Daten werden öffentlich auf dieser Website und im offenen Quell-Repository auf GitHub gespeichert.

Die Einwilligung kann jederzeit mit Wirkung für die Zukunft widerrufen werden — formlos per E-Mail an die im Impressum genannte Adresse. Der Eintrag wird dann zeitnah entfernt; auf Wunsch auch aus der Versionshistorie des Repositories.

5. Eintragung über GitHub

Die Selbsteintragung erfolgt wahlweise über ein GitHub-Issue (dabei gelten die Datenschutzbestimmungen von GitHub; der GitHub-Nutzername wird im öffentlichen Repository sichtbar) oder per E-Mail an das Team.
